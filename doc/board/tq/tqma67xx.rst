TQMa67xx[L]
###########

Base boards / configurations
----------------------------

Supported combinations of base board and module:

- TQ-Systems MBa67xx (REV.010x) with TQMa67xx (REV.010x)
    - tqma67xx_mba67xx_r5_defconfig
    - tqma67xx_mba67xx_a53_defconfig

Supported RAM configurations (LPDDR4):

- 2 GiB
